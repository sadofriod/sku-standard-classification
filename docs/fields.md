每个文件、每一列、每个枚举值的含义。示例取自真实运行结果（1,000 条），已脱敏。

| 销售单位 | 筒 | 原文字段，属性「数量/包装」的辅助证据 |

| 待核实项 | 必填缺失:总打印页数\|是否带芯片 | 需人工确认的原因，`;` 分隔，详见 §5 |
| 属性JSON | {"产品名称":"长尾夹",…} | 该行**所有已填属性**的键值对（只含有值的项） |

## 3. `来源` 的取值

| 值 | 含义 | 置信度 |
| --- | --- | --- |
| `column` | 直接取自结构化列（商品名称/品牌/制造商型号/型号/销售单位） | 1.00 |
| `title` | 由标题的确定性规则抽出（包装 `48只/筒`、规格 `25mm`、颜色 `黑色`、枚举关键词） | 0.99 |
| `llm` | 模型按 03 模板抽取并通过校验（枚举命中候选、数值可解析） | 0.99（双盲实测 99.2%） |
| `graph` | 同型号传播（同品名 + 同一型号的其它行取值） | 0.90 |
| `graph_infer` | 图谱上下文/开放世界/单条重试推断，必带 `依据` | 0.80–1.00，按组合留一法 |
| `missing` | 无证据，留空 | 0 |

---

## 4. `字段类型` 与校验规则

| 类型 | 规则 | 违规处理 |
| --- | --- | --- |
| 文本 | 去空白、全半角归一，长度 ≤120 | 超长截断 |
| 数值 | 必须是纯数字（可带小数） | 取不到数字 → 丢弃该值 |
| 枚举 | 只能取 03 模板 `属性值` 里的候选（多值用英文逗号连接） | 越界 → 丢弃该值 |

颜色类属性另有规则：值必须在标题里逐字出现（支持 `透明`、`象牙白`、`原木色` 这类不在色卡上的写法），否则留空。

## 5. `待核实项` / `复核队列.复核原因` 的取值

| 值 | 含义 | 建议动作 |
| --- | --- | --- |
| `两表口径冲突` | 02 表与 1-4 级复核表的路径不一致（本批 5 品名 / 441 行） | 看 `待裁定_口径冲突.csv` 拍板 |
| `必填缺失:属性A\|属性B` | 这些必填属性在标题里没有证据 | 人工补或确认放弃 |
| `推断待确认:属性A` | 该属性来自推断（`graph`/`graph_infer`），需抽检 | 抽检 5%~10% |
| `标题命中其他标准品名:X` | 标题里出现同中类的其他标准品名，可能错分 | 人工判定 |
| `品名未收录于02表` | 输入品名不在 02 表里 | 需业务补目录 |
| `复核口径缺分类代码` | 选了 reviewed 口径，但该路径在 02 表里没有代码 | 需业务补代码 |

## 6. `标准分类与标准属性.csv`（两列主交付）

| 列 | 示例 | 含义 |
| --- | --- | --- |
| 原表行号 | 19 | 对齐键 |
| 商品标题 | 得力 8564 长尾夹… | 原文标题 |
| 标准分类（1-4级） | 办公设备及耗材 / 办公文具 / 夹类 / 票夹 | 用 ` / ` 连接的 4 级路径 |
| 分类代码 | 250805 | 6 位代码 |
| 标准属性 | 产品名称：长尾夹；品牌：得力；… | 用 `；` 连接、`：` 分隔键值的可读串 |
| 标准属性JSON | {"产品名称":"长尾夹",…} | 同一份内容的机器可读形式 |

带 `_conf0.95` / `_conf0.9` 后缀的版本只保留置信度不低于该门槛的推断值（见 `confidence-report.json`）。

| 列 | 含义 |
| --- | --- |
| 品名 | 冲突的品名 |

## 8. `metrics.json` / `confidence-report.json`

| 键 | 含义 |
| --- | --- |
| `cells.total` / `filled` / `fillRate` | 属性 cell 总数 / 已填 / 填充率 |
| `bySource` | 各来源贡献的 cell 数 |
| `required.total` / `filled` / `rate` | 必填 cell 总数 / 已填 / 覆盖率 |
| `rowsFullySatisfied` | 必填全部满足的行数 |
| `llmHallucinations` | 模板外属性数量（应恒为 0） |
| `reviewRows` | 进复核队列的行数 |
| `coverageByThreshold` | 置信度门槛 → 已填 cell 数 / 覆盖率 / 预计错值 |
| `tiers` | 各置信度层的 cell 数与平均精度 |
